packaging: select libc++ for the platform Clang toolchain

Add libc++ development dependencies and C++ compile/link flags only when
_toolchain is defined and toolchain_is clang is true. Preserve the GCC path
and configurations that do not select this platform toolchain. The tested
armv7l and aarch64 source-built programs and their LLVM/BCC providers use
the same standard library in each configuration.

The static subpackage still contains precompiled assets that were not
rebuilt by this change. Their origin remains unconfirmed: neither binary
matches the currently published upstream v0.24.2 release artifacts. The
embedded C++ standard library was not observed. The subpackage is absent
from the six inspected product image manifests; this does not exclude
later test installations or other images. Its existing post-install
replacement of /usr/bin/bpftrace is unchanged and tracked separately.
