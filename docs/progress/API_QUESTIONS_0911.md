## 本轮续测新增的未决条件与判断

11. **真实 vector 回调**：已找到浏览器实现与有效实例要求，service 实现只是“不支持”的 no-op。x86_64 初始化等待 Wayland 超时；ARM 未建立真实 Web 应用/插件会话。没有使用假回调/无效实例填格。需要可复用的真实注册/初始化流程及两套构建组合。
12. **Dali 整套组合**：属性包装子集双向通过；完整 GNU binder 在只迁 core 后，因旧 adaptor 导入的 GNU vector 方法名无法解析而失败。此证据不等于任意组件两两都必须同批；也不等于完整 libc++ Dali 与旧 binder 的组合已测。
13. **Dali 图形/虚调用**：完整 GNU 同侧 Control::New 前置试跑也失败，当前没有有效的该路径正向对照。不归因为跨库问题；还需真实图形/核心初始化环境。
14. **EWK shim 原型已知问题**：完整 cookie/空输出时 5/5 通过；复用预置输出且输入省略 Domain/Path 时，5/5 把真实直接调用会保留的字段清空。原型未改成生产方案，不能交付为已保持全部语义的兼容层。
15. **表示与接口区别**：GNU 14.2 与 libc++ 的 vector 普通配置三个指针表示在四种状态下相符；不等于实际 SetSyncBinaryReply 的跨库赋值/销毁已验证。Dali 属性字符串是 Dali::String，不是 std::string。
16. **本轮执行解释**：真实 binder 源码子集与完整 binder 分开；用隔离 Tizen 加载器；ARM 包装编译器失败后用原生 Clang 交叉生成 ARM；ARM 探针仅在进程内记录故障信号并失败退出，避免板端诊断残留。最终规范矩阵均有最终源码快照；中间版本和若干展示日志的读取命令未全量单独封存。详见 W1_CONT/SCRIPT_VERSIONS.md。
