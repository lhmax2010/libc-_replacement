Build static libclang for libc++ toolchain builds

Build the static libclang archive when build_with_libcxx is set.
It is required by the bpftrace static subpackage built from source
(bpftrace 7831fb34c6881b5cff0b8bdd0dac27a1829290fa).

Keep the GCC and undefined-toolchain paths unchanged. The existing
llvm-static-devel file list includes the new archive.

Verified with full LLVM RPM builds on armv7l (22 RPMs) and aarch64
(12 RPMs). Both libclang.a archives contain libc++ symbol markers;
the checks found no std::__cxx11 markers within the covered searches.
