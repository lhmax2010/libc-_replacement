Build static libc++ and libc++abi archives for clang toolchains

Build and install the static libc++ and libc++abi archives when the
toolchain is clang, as required by the bpftrace static subpackage built
from source (bpftrace 7831fb34). Package the archives only under the
same condition.

Keep the shared libraries, ABI linker script and unwinder settings
unchanged. With the GCC override, a literal GCC toolchain or an undefined
toolchain, all four static build/install switches remain OFF and the
archive file entries are absent.

Verify the four macro combinations against the baseline in the retained
ARM build root, ignoring pure blank lines left by macro definitions.
