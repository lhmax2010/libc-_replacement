Build the static libclang archive for libc++ consumers

Build libclang.a when build_with_libcxx is set, as required by the
bpftrace static subpackage built from source (bpftrace 7831fb34).

Place LIBCLANG_BUILD_STATIC alongside LLVM_ENABLE_LIBCXX under the
existing build_with_libcxx condition. Apart from this option, spec
expansion is identical to the baseline under the default configuration,
_toolchain_override gcc, _toolchain gcc and undefined _toolchain.
llvm.spec already forces clang through _toolchain_override when
_toolchain is defined; this is not a new GCC override guarantee.

Verified by full LLVM RPM builds on armv7l (22 RPMs) and aarch64
(12 RPMs), with the libclang archives using libc++ symbols and no
observed std::__cxx11 symbols.
