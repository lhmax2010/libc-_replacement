METHOD_REFINEMENT

Command 095 successfully extracted and inspected all archives, but its broad
`_Z*` count includes local Clang fortify wrappers from C objects and GNU vector
ABI names such as `_ZGV*`.  Independent command 099 showed that `nm -g` removes
the local wrappers and that `c++filt` does not decode the vector ABI names.

The final rerun therefore counts only externally visible (`nm -g`) definitions
whose names are actually transformed by `c++filt`.  Command 095 remains useful
as extraction evidence but its 986-row preliminary count is not the final C++
archive denominator.
