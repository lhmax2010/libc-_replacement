    Package the libc++ runtime copied into the clang accelerator
    
    The clang binaries copied into /emul depend on libc++.so.1 and
    libc++abi.so.1. These libraries are copied but not added to the clang-accel
    file list, so rpmbuild fails with unpackaged files. Add their SONAME paths
    to the list before final de-duplication. Update the template and all three
    generated specifications together.
    
    Change-Id: I8b578a992218d1111569cf01fdb97977cbaabe4e
    Signed-off-by: Hao Lin <hao.lin@samsung.com>
