    libc++ in Tizen-Base-Toolchain. Pass the upstream CLANG_USE_LIBCPP option
    when the toolchain is clang so both sides use the same C++ standard library.
    The installed headers are unchanged. GCC and undefined-toolchain builds
    are unchanged.
