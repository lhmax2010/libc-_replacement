    Use -iquote for the tz2icu source directory
    
    The tzdata archive extracted into tools/tzcode contains a file named
    "version". With -I. it shadows the C++ standard <version> header and breaks
    the libc++ build of tz2icu. Use -iquote to keep quoted local includes
    working without exposing that directory to angle-bracket includes.
    
    Apply the new patch after the existing packaging patches, preserving
    the LINKFLAGS added by the PIE patch.
