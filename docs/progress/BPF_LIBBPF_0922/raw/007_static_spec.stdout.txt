66-BPFtrace is a high-level tracing language for Linux enhanced Berkeley Packet
67-Filter (eBPF) available in recent Linux kernels (4.x). BPFtrace uses LLVM as a
68-backend to compile scripts to BPF-bytecode and makes use of BCC for
69-interacting with the Linux BPF system, as well as existing Linux tracing
70-capabilities: kernel dynamic tracing (kprobes), user-level dynamic tracing
71-(uprobes), and tracepoints. The BPFtrace language is inspired by awk and C,
72-and predecessor tracers such as DTrace and SystemTap
