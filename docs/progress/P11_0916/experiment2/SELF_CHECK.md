## 保留的失败与修正

1. `raw/007*`：GNU ld 网页 curl HTTP 403 / 退出 22。网页读取成功与 curl 失败分别说明，不写成全部网络请求成功。
2. `raw/023_summarize.*`：汇总脚本调用 `hashlib.file_digest(check,'sha256').hexdigest()`；当前 Python 无该函数，退出 1。仅将这一句改为循环读取解压数据计算 SHA256，`raw/024_summarize_retry.*` 退出 0。原始扫描、RPM 身份和五轮测量没有重写。该汇总辅助脚本没有加载平台代码。
3. 初次 armv7l 反汇编没有指定 Thumb，`elf_09_forwarder.stdout` 中出现错误模式指令；以 `raw/021_arm_thumb_forwarder.*` 为正确模式记录，并用 `raw/022_arm_relocations.*` 独立核对 dlsym 落点。
4. 初次目录探查中的缺文件信息保留；后续实际输入路径与摘要见 `INPUT_IDENTITY.json`。组合 shell 命令的退出码是整个命令的退出码，不表示其中每个 rg/sed 子命令都成功。
5. 无节表引导镜像的自动扫描异常保留在 `UNAVAILABLE.json`；独立程序头/动态段补查另存 `raw/020_boot_dynamic.*`，没有抹掉原异常。

最终交付校验与远端核对另存 delivery；报告不声称不存在任何未解决的问题。
