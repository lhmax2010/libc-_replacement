## 旧表受影响条目的更新

编号仅用于此内部处置记录，方案正文不使用内部任务代号。

| 原条目 | 本轮生效处置及理由 |
| --- | --- |
| O02：普通异常与取消分开 | 继续采纳。本轮只补普通异常归因，不将原取消成功外推全部路径；旧取消记录保留 |
| O03：原类型信息实验已解释 BoundaryError | 原强制展开实验不能替代它；本轮新增直接 BoundaryError 轨迹，类型匹配原因已测，不能倒写成旧实验已证明 |
| O04、L03：名字深比较宏 | 仍待评估，未实验；改为原样本不是 foreign，宏是否保持全部语义仍待定，不再用 foreign 作为原样本的既定成因 |
| O18、K43：new/delete 与异常类 | 保留有限绑定证据，未新增分配释放或九类异常矩阵，不把 GNU ABI 对照成功扩成全部异常类通过 |
| K03：personality 与共存契约 | 更新为已有实际 throw/personality/标识和配置对照，异常契约未闭合，不再统称未测 |
| K20：版本、VERNEED 与绑定验收 | 已做旧目标版本和转发结构核查；旧应用人群缺口保留，生产路由尚未验收 |
| K27、L02：共享低层 ABI 运行时 | libsupc++ 已实构建并对照，成为关键路径候选；不实施 libcxxrt/其他平台方案，不宣称共享 ABI 自动统一布局或取消 |
| C21、C25：部分写入与已知异常协议 | 原条件性设计保留；本轮运行时观察不是已实现的跨界异常序列化/本地重抛层 |
| L04：空消息 _S_empty_rep_storage | 继续延期，未实施实验 |
| L08：veneer 原型 | 继续延期；新增薄壳候选位置及 dlsym 前提是推论，不等于原型已部署 |
| 旧人工映射“四项本轮不做” | 为历史限制，当前人工授权已改变：libsupc++ 已测并升候选，其余三项仍延期 |

## 自行判断与未决

本轮第二轮评审的具体作者没有由人工任务书指明，来源记“人工转述”，不自行归给某一家。libsupc++ 等原四项的 Claude Code 归属保持旧原文依据。开头补充的作者身份仍待确认，不阻碍事实核查。

新增而必须保留的限制：LLVM 同侧也失败；ARM GNU ABI/LLVM 展开器中止；初始 ARM 读参无效的范围；旧 ABI 与新构建并非排除全部混杂因素；真实反向 EWK 仍无产物。没有为了统一结论删去反例。
