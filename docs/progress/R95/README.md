# R95 材料索引

- `REPORT.md`：调查结论、口径、选项和盲区。
- `SUMMARY_COUNTS.tsv`：主要计数。
- `OPTIONS.tsv`：各处置方向的客观范围与遗留风险；无排序、无推荐。
- `evidence/KEY_EVIDENCE.md`：关键证据与原始日志索引。
- `tables/`：完整清单和逐边分类表。
- `code/`：本轮解析、扫描汇总和分类程序。
- `raw/`：命令原文、标准输出、标准错误和退出码。
- `inputs/actual_repositories.tsv`、`inputs/image_packages/`：冻结的仓库地址和 14 份镜像包清单。

本任务只调查与分析；没有修改配置、平台源码或补丁，没有实施迁移，也没有向 Gerrit 推送。
