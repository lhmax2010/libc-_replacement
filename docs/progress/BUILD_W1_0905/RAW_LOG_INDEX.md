# 原始记录索引

`raw/` 中每个序号对应四个文件：

- `*.command.txt`：实际命令；
- `*.stdout.txt`：标准输出；
- `*.stderr.txt`：标准错误；
- `*.exitcode`：退出码。

重点记录：

| 序号 | 内容 |
|---|---|
| 001–006 | 资源门禁、磁盘、初始仓状态、任务书身份与全文 |
| 018–028 | 远端分支身份、fetch、只读工作树创建与核对 |
| 029–055 | 指南定位、全文、脚本全文、分支内容和模型 SHA256 |
| 061–064、074–075 | 两个模型 ZIP 的完整性与内容 |
| 071、076–078 | 交叉支持 config 与实际启用情况 |

| 088–092、095 | 标准库选择、LLVM spec 输入接口与旧资产符号证据 |
| 093–096 | 时间、项目分支、Source 数和未生成状态 |
