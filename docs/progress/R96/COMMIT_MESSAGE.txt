packaging: select Clang explicitly for libc++ runtimes

Select the target-prefixed Clang drivers directly in the libc++ runtimes
CMake configuration.  The previous package-local _toolchain_override did
not affect the RPM compiler macros in the Tizen-Base build environment, so
GCC was still selected and rejected the Clang-only --rtlib=libgcc option.

When an aarch64 GCC-default environment invokes this Clang-only package,
normalize only the GCC-specific composite -mtune value to cortex-a53.  This
matches the value already supplied by the LLVM project configuration; all
other environment flags remain unchanged.

The resulting spec was built in the armv7l and aarch64 GCC-default and LLVM
environments.  All four builds used Clang 22.1.8, completed successfully,
linked libc++ and libc++abi against libgcc_s.so.1, and installed the five
checked forced-unwind header changes.

_toolchain_override 在 Tizen-Base 环境中不会改变 RPM 编译器宏，因而
仍会选中 GCC。对于“GCC 默认环境中由本包指定 Clang”的 aarch64 组合，
仅将 GCC 专用的复合 -mtune 参数规范化为 LLVM 配置所用的 cortex-a53；
其余参数保持不变。两架构、两环境共四格验证均已通过。
