共 138 项已有本轮口径下的定界结果，94 项由未定收窄；62 项仍未定。RUNTIME_CALL 主分类为零不表示没有运行库调用：既有运行库关系单列保留，不足以证明候选“仅调用运行库”时不强行归该类。PUBLIC_NO_CONSUMER 同理，未因没有名字交集而补判。

NO_STDLIB_OBJECT 的 89 项分为：BUILTIN_ALIAS 4、COMPILE_TIME_ONLY 65、EMPTY_TYPE 20。结构实测仅 x86_64，C++17，libstdc++ GCC 14.2 头 / libc++ 22.1.8 头，两个独立构建、每侧每项 5 次。逐项具体值、两侧定义位置和平台实际用法见 `items/`、`A_RESULTS.json`、`A_DEFINITIONS_*.json`。这些是结构探针，不是新包间运行实验。

四个内建别名实际展开：size_t 为 unsigned long，ptrdiff_t / streamsize 为 long，nullptr_t 为 decltype(nullptr)。二者 sizeof 均为 8（当前 x86_64 配置）。20 个空类型实例均 sizeof=1、is_empty=1。高精度时钟别名两侧目标不同但均为空，不能由此推断时间语义相同。类型投影结果仍可能有存储：aligned_storage<8,8>::type 实测 8 字节，不将它的运行期存储消失掉。
