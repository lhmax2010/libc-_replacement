# 自检与未完成项

## 可核结果

- 主矩阵按真实目标/实际架构分开，16 格×5 次=80 次尝试；没有合并初版 Dali 重跑、表示探针、shim、环境诊断。60 次具体值符合不是全部需求覆盖率。
- EWK GNU 正向对照与混用故障均有两架构各五次。SIGSEGV 发生后四字段未观测，未填成错字符串；ARM 信号记录方式与原生默认终止区分。
- Dali 属性子集两个方向和两种同侧对照均有两架构各五次；完整 GNU binder 同侧额外对照通过。只迁 core 的完整依赖链加载失败单列，未当作字段运行格。
- 加载失败不可能满足完整 binder 的 maps 断言，报告保留 maps=0，并有实际 core 的加载前映射。其他规范目标格均检查完整映射。
- vector 检查真实对象的三个机器字与 data/size/capacity，并断言具体字节；使用 GNU 14.2 平台头文件补充，未冒充真实回调实测。
- EWK shim 既保留正常固定样本通过，也保留复用输出的五次语义不一致；未以“未崩溃且析构完成”代替正确性。
- 实际源码归档对照有内存变异正向对照；符号未命中的判断限定在指定 ELF 动态导出表，另有已知导出正向命中。未把未观测写成不存在。
- 板端上传清单 SHA256 一致，清理返回 0，并确认独占目录不存在。没有清理他人目录、运行库或配置。
- 原始材料、最终代码快照与 SHA256 留档；构建物不入 git；两份既有 R115 脏文件的 SHA256 保持不变。

## 不能标“完成”的要求

1. **EWK 反方向与 libc++ 同侧格**未跑：缺配套真实 libc++ Chromium provider；两架构一样不能据已测方向外推。
2. **SetSyncBinaryReply 的真实实例回调格全部未完成**；浏览器与 service 的实现已区分，不能用 no-op 或向手写回调传 vector 代替。
3. **完整 Dali 图形/虚调用及完整 libc++ 依赖组合**未验收；属性包装子集不代表完整 binder，core 不是整套 Dali。
4. **目标 shim 部署仍未确认**：EWK 原型已发现输出复用语义缺陷，其他两组没有目标专用部署实测。异常、迭代器、所有权的普遍转换无实测承诺。
5. 中间脚本版本及全部交互读取命令的审计有缺口，见 [版本说明](SCRIPT_VERSIONS.md)；不影响最终规范矩阵有最终源码/构建命令/输出，但不能报告所有审计要求全量通过。
6. 原 W4 的中英文材料只是旧轮可审阅稿；状态页已增加续测中英文入口，原稿正文保持封存。本报告不是替它们做一次完整对外稿改写或新一轮人工审阅。

最终判定：**PARTIAL，材料可供人工审阅；不作接口全面支持或 shim 可部署承诺。**
