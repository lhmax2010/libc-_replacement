# 产物归档口径

本目录归档了每条命令的原文、stdout、stderr 与退出码，以及全部报告、矩阵、
验证脚本和 R103 精确归档成员匹配表。

GBS 构建根、RPM、解包后的 payload 与 `nm` 全量符号临时文件体积约数 GiB，
它们是可由本目录命令和远端软件仓重建的中间产物，没有复制进项目 Git 仓。
逐包/逐 ELF/逐归档的检查输出已完整写在对应验证命令的 stdout；R103 的
`member_matches.tsv`、`summary.tsv` 与子命令账本则作为小型派生产物一并归档。

本机交接时的中间产物仍位于：

- `progress/R105/artifacts/`
- `tmp/GBS-ROOT/R105-*`

它们不作为项目仓提交的一部分，也不作为结论唯一依据。
