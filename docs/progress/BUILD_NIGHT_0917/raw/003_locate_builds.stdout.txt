    spec: enable FORCE_STATIC_LIBBPF for static package build
    
    Add -DFORCE_STATIC_LIBBPF=ON cmake flag to enforce static libbpf
    linking in bpftrace-static package. This ensures the binary doesn't
    depend on libbpf.so.1 and can be used as a true static binary.
    
    Also add build-time verification using ldd to check for libbpf.so
    dependency and warn if found.
