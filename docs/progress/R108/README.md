# R108 产物导航

- `REPORT.md`：总报告
- `W1_REPORT.md`：源码与发布文件核查
- `W2_REPORT.md`：不重建组件清单与上界
- `W3_REPORT.md`：两个组件的静态路径与正交探针
- `code/`：本轮脚本和探针源码
- `tables/`：逐项清单、分类、汇总与源码快照
- `raw/`：命令、stdout、stderr、退出码和哈希快照
- `build/`：正向对照和 x86_64 探针构建物
- `MANIFEST.sha256`：全部产物的 SHA-256 清单

状态表与待人工输入分别位于相邻的 `RUNTIME_STATUS_0905.md` 和 `RUNTIME_QUESTIONS_0905.md`。
