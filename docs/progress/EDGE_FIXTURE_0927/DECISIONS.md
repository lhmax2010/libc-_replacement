# 执行口径与自行判断

1. 输入只取固定边表与逐边前置表；保持 23 行及原始 mangled 名，不把当前包的新接口替换成原边。
2. 将两个 reference 的 build.xml 解析为具名快照后下载；URL、仓库摘要、RPM SHA 和版本身份分别保留。新包可能不同于旧 ELF 证据，须独立核符号。
3. 只解包，不安装 RPM、不运行安装脚本、不启动系统服务、不修改平台配置；依赖只按当前元数据 SONAME 取唯一提供者，歧义列缺口。
4. 运行是 x86_64 GNU/GNU。标准库、编译器和提供方输入参数化不等于已测 libc++；切换后须有匹配的新符号清单及同侧控制。
5. 生命周期计数表示夹具实际调用所列公开类型构造，并在 reset 返回后记录析构完成；不声称证明提供方内部无泄漏。需要真实接管/回调销毁而无法构造的，不用空对象凑通过。
6. 每轮先检查精确 UND，启动 maps 必须含传入的提供方真实路径；提供方 SHA 在启动前与退出后校验一致。夹具输出 SHA 由运行脚本计算并传入，非夹具自实现哈希。
7. 当前任务新闸门规则替换备案的旧“即停”规则：失败之间十分钟，连续六次失败停止；硬截止北京时间 2026-09-28 08:30。

8. 当前 GNU 包与历史边的版本不一致时不换题：GetMatches 的 array<int,4> 变为 array<int,5>，准确旧符号未找到而新签名导出可找到；标 NOT_AVAILABLE，等待匹配包或人工变更登记范围。
9. Scene 最初在主线程读取更新线程专用回调队列，是夹具错误，不是兼容性发现。留存错误源码和失败记录；改为公开离屏 Application/渲染事件路径后，在 Start 的 EGL 前置处仍终止，尚未触发目标。WebView 同样不放宽回调/对象销毁断言。
10. Singleton 初版无 Application 得到空服务而退出 77；补公开 OffscreenApplication 工厂构造、不启动渲染，才取得实际服务并完成类型键、属性 42、弱引用销毁断言。加载了三份宿主 C 图形库，逐轮 maps/SHA 公开，不把目录隔离说成镜像隔离。
11. GoogleTest 诊断的最初完整字符串断言漏最后一个换行，五次失败；按实际公开行为修正测试预期后重新五次通过。保留失败，不称 provider 差异。
12. Delta 缺成功输入不能拿五次错误返回替代正向对照；附加示例/测试 RPM 补查仍未取得可认定的 Delta 文档。cert-svc 签名样本已取得，缺的是可隔离信任环境与确定结果契约，而不是所有材料都不可得。详见 DATA_FOLLOWUP.md。
13. 实际 GNU 输入为当前 x86_64 快照；仅编译小夹具，未构建任何 provider。用 Clang 的 libstdc++ 配置建立 GNU 标准库基线，不称 GCC 前端。compiler/sysroot/flags/宏/包 SHA 全部回链。
14. 任务源码、声明、包清单与最终结果 SHA 绑定；历史不合格尝试保留但不计有效基线。16 条 × 5 轮只是固定样本，不是“16 个包已通过”、不是平台运行兼容，也不新增/删除原 23 条登记边。
15. 当前材料把支持包列在主 provider 之外：Dali 工厂需要 adaptor，WebView 后续还有 chromium/lwe 插件选型；未擅自替组件方选择产品插件。编译线交付输入须覆盖对应依赖，不仅换一个核心 .so。
16. 固定备案按惯例更新第 3/4/6/8 节；同时修正第 2 节阶段状态、第 9 节开场状态以及顶部版本说明，避免还称“本次未授权启动”。历史事实不改；新材料同 commit 引用不编造自引用 SHA。
17. 全量 RPM 摘要复核第一次超过包装器 120 秒超时，保持低优先级、仅延长只读检查超时后完成；随后自检曾把尚待生成的 AUDIT.json/SHA256SUMS 当作坏链接，已修正生成顺序并重验。失败原始记录均保留，不将它们算作目标库运行失败。最终封存时再核验这些文件实际存在。

## 尚需确认/提供

- GetMatches：匹配登记符号的头/库，或人工确认新版本边的替代范围。
- Scene/WebView：真实可运行 EGL、平台配置、帧/页面事件；WebView 还需产品插件选型。
- Delta：有来源的成功 Delta 文档与三组预期文件列表。
- cert-svc：可隔离的信任库、schema、验证插件/配置及期望结果；不修改本机安全环境。
- 推理：真实后端插件、配置、模型与输入张量契约。
- 私有文件共享：真实应用身份、服务、文件与权限核验环境；不模拟、不改宿主权限。
- 所有混合方向：libc++ 构建的逐边 provider/-devel/依赖、同侧控制及独立符号身份，按 LIBCXX_INPUTS.tsv 对接。

上述缺口已分别登记，不因其中一条受阻而停止其他条目。没有自行决定产品部署或绕过测试断言。
