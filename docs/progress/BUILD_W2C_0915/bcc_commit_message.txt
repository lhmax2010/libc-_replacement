packaging: use libc++ with the platform Clang toolchain

Add the libc++ development dependencies and C++ compile/link flags only
when _toolchain is defined and toolchain_is clang is true. Preserve the
GCC path and configurations without the platform toolchain selection.

仅在平台 Clang 工具链路径启用 libc++，保持 GCC 路径及未启用该工具链
配置的现有行为。改动仅涉及打包参数，不修改上游 C++ 源码。
