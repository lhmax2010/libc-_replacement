# R112 材料索引

- `REPORT.md`：逐项事实核对、严重度清单、复现性与附件结论。
- `SUGGESTED_REPLACEMENT.md`：可替换原稿的英文回复全文。
- `FACT_CHECK.tsv`：各项声明、判定、证据和建议的机器可读表。
- `RECOVERED_TECHNICAL_ERRORS.md`：已恢复的校验器技术错误。
- `ARTIFACT_SHA256.txt`：提交前非原始日志产物的 SHA256 清单。
- `code/`：只读核对脚本快照。
- `raw/`：命令原文、标准输出、标准错误和退出码。

本轮没有修改待审核英文原稿、R110 材料、源码、配置或既有判定。
