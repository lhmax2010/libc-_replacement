# R73 自行判断与尚存疑问

## 自行判断

1. 将 R72 的 35 source RPM / 26 包名保留为宽词法上界，另以显式 `std::`/`using std::` 形成 11/9 的精化口径。
2. 对全部 9 个显式命中包名做上下文复核，而非再抽取更小子集。
3. “0 个生产包确证风险形态”只表示没有在同一源码树中闭合等待点与取消发起者，不表示这些包安全。
4. D01–D05 的常见性只按所需前置条件多少定性，不冒充运行频率。
5. 没有新增运行实验，复用 R72 的动态样本；D02/D05 保持 `NOT_OBSERVED`。

## 尚存疑问

1. 是否有包外宿主或闭源组件取消上述 9 个包的等待线程，现有源码材料无法回答。
2. LLVM 是否存在换词或未索引的讨论；精确查询均为 `NOT_FOUND`。
3. D05 的动态现场与产品使用频率均未取得。
4. 若未来改 D01/D02，旧消费者 ABI 的具体平台承载方式尚未裁决。
