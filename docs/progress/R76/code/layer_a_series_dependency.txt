Series dependency:
These four commits form one validation series and must be applied in this
order: Layer A, Layer B, Layer C header batch, then Layer C library batch.
Do not apply or validate only a subset. Both Layer C batches require Layer B
and, on ARM, Layer A. Applying Layer A without the remaining series is not a
supported deployment and can introduce a regression.

系列依赖说明：
四个提交构成一套验证系列，必须按层 A、层 B、层 C 头文件批、层 C
库内批的顺序应用。不得只应用或验证其中一部分。两个层 C 批次均依赖
层 B，并在 ARM 上依赖层 A；只应用层 A 而不带其余系列不属于支持的
部署形态，可能引入回归。
