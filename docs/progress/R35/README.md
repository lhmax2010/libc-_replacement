# R35：结论链关键代码补充审阅材料

本目录仅整理并逐字复制 R30–R33 已存在的源码、脚本、命令记录、
运行输出和结果表，供人工审阅。此次没有重新构建、重新运行实验、
修改平台源码或修改既有验证代码，也不对材料作分析或下结论。

## 目录

- `R30/`：初始与诊断变体语义用例、构建/运行原文、候选补丁及
  两个被改文件的候选提交当前全文。
- `R31/`：受控矩阵源码、构建 spec、运行器、personality 观测器、
  逐格输出与 GDB/personality 原始记录。
- `R32/`：影响面扫描/归类源码及完整分类表、四方向用例、构建与
  逐格运行输出、机械汇总脚本与结果。
- `R33/`：S2 契约材料、非强制 foreign 用例和输出；S4 上下文提取、
  分类脚本、50 处上下文与完整分类表。
- `INDEX.tsv`：每份材料的来源任务、原路径、上传路径、SHA256、状态。
- `MISSING.tsv`：既有证据中不存在的请求项及缺失原因。
- `MANIFEST.sha256`：本目录材料的 SHA256 清单。
- `EXCLUDED.tsv`：超过单文件 5 MB 的排除登记；本次为零。

## 原件边界

`R30/current/` 下两份完整目标文件来自各自源码仓当前 HEAD；当前 HEAD
分别就是 R30 已归档的候选提交：libcynara-commons
`5ba41186b38682290575ceff60143c9009e531f7`、security-manager
`dffe51106564d8db0a40b6ff7c01d6fcece816af`。其余材料均保留在
`INDEX.tsv` 所列既有路径中，并以逐字比较核验。

本目录不补造当时未采集的运行轨迹；缺失项以 `NOT_AVAILABLE` 登记。
