# R32 证据包

主报告：`R32_report.md`。

- `commands/`：命令原文、输出和退出码；被否决或中止的扫描/构建尝试也保留。
- `inputs/`：受控实验的 RPM spec。
- `src/`：候选方向受控实验的完整源码。
- `results/native_matrix/`：x86_64 宿主原生逐格记录，不使用 QEMU。
- `tables/`：371 包影响面、迁移阶段映射、首批两包取消路径、候选行为矩阵和 R30 红项定性。
- `tools/`：补扫、实验运行、汇总和取证脚本。

本任务未修改平台源码、R30 候选补丁、既有制品或既有文档；构建仅用于 `progress/R32/` 中的独立实验件。
