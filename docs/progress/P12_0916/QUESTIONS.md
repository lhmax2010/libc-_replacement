# 疑问、自行判断与发布前缺口

1. **待人工确认的错误合同**：原函数仅返回 Eina_Bool。候选对加载失败/被捕获分配错误返回 false、设置 errno、保持输出；解析正常返回保留 provider errno。这改变原实现可能抛异常的可观测行为。已异步提问，未收到裁决前只作为候选合同。
2. **已实测发布阻断**：后端真实分配失败 5/5 SIGABRT；typed catch 没有实现预期错误返回。是否在本轮扩展异常运行时隔离实验，已异步提问。不能未经验证用 catch-all 或切 ABI 配置消除此问题。
3. 生产方向缺真实 libc++ chromium-efl；不模拟。迁移后须给实现库、依赖、公开头文件/配置、编译器与 ABI 命名空间证据。生产测试入口需要按该配置构建两个应用探针、三种转发对象后填 manifest。
4. 真实 SetSyncBinaryReply 宿主/注册路径不可得。现有补测脚本只是定义输入输出的编排契约，还缺连接真实回调的 driver。不能给业务方说“只差一个库文件就能跑真实路径”。
5. 同侧解析器的极大 Max-Age 溢出相关负 expiry 已观测。本任务没有修改平台 parser 或擅自更改输入规则；此项不是 adaptor 的正确性背书。
6. 两种部署形态均给出，但不代替人工选择。GN/spec 补丁仅干净应用及双 TU 构建验证，产品 RPM/镜像部署未验证；编译配置和开发依赖包名未凭空补齐。
7. 实际测量使用 non-TV 转发配置、GNU ABI=1；不能外推到 TV 初始化、其他产品 ABI 命名空间、旧 GNU ABI=0 或所有应用。工程编译固定使用当前 SDK，接口版本/产物固定 SHA；将来 ABI 漂移须重新验证。
8. 自行判断均已披露：保留所有调用前字符串、不读旧 expiry；只交换有变化的字段；绝对实现路径+根 DSO 校验；句柄进程终身保留；不吞未知异常；空字节串允许空指针，非空借用区由调用者负责有效性。上述是候选实现选择，不是已获生产契约裁决。
