    - MLGO AOT (Ahead-of-Time) compilation support for LLVM regalloc models
      * Support for ARM (armv7l) and AArch64 architectures
      * Pre-compiled MLGO models included (mlgo_arm_model, mlgo_aarch_model, mlgo_x86_model)
      * TensorFlow AOT compiler integration via TensorFlowCompile.cmake
    
    - Build system enhancements
      * Refactored packaging with project_config-driven mlgo bcond
      * XLA runtime support (pre-compiled .o files)
      * BCC compilation issue fixes
      * Architecture-specific optimizations
    
    - Configuration updates
      * Updated llvm.spec with MLGO AOT targets and xla_runtime artifacts
      * Enhanced CMakeLists.txt for MLGO AOT compilation workflow
      * TENSORFLOW_AOT_COMPILER path configuration for Tizen package layout
    
    This enables machine learning-guided code generation in LLVM builds while reducing
    external dependency requirements by using pre-compiled models.
