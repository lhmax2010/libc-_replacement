# 恢复记录：未经过包装器的只读显示命令

本轮开始时及查看已生成日志时，有一组只读 `sed`、`cat`、`head`、`tail`、
`find`、`git status`、`du` 显示命令直接运行，没有由日志包装器自动生成四件套。
这些命令没有修改任何文件，其显示对象均为已经落盘的既有材料或本轮 `raw/` 文件，
也没有产生用于判定的独有数据。

处置如下：

1. 所有用于提取新统计、哈希、证据链和最终校验的命令均已通过包装器重跑并保留
   command/stdout/stderr/exitcode；
2. 未包装的显示结果可由相应已归档文件原样恢复，不把对话窗口中的截断显示作为
   证据；
3. 首次直接执行无执行位的临时包装器所产生的退出码 126，已在
   `009_inspect_key_tables.stderr.txt` 中作为恢复说明记录；
4. `040_archive_earlier_logs_bash` 的参数拼接错误及退出码 127 有完整四件套，随后
   `041_archive_earlier_logs_retry` 已成功重跑；
5. 本记录是事后恢复说明，不冒充日志包装器自动生成的原始记录。

以后应从第一条命令起直接使用归档目录中的包装器，查看日志本身也应通过同一包装器，
避免再次产生这类恢复记录。
