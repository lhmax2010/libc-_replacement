# 续跑的统计口径与材料缺口

两批均未将“未观测”补成“不存在”。以下问题已向人工提出，尚未收到答复。

1. 内置类型别名（例如 `size_t`）、计算后变成其他类型或 void 的别名，以及仅作类型参数的 clock/ratio，是否单列为“非独立对象候选”？它们不应仅凭名字出现在符号或头文件中就计为标准库对象跨包。
2. 是否允许在冻结安装头与已扫描 ELF 的明确覆盖范围内给出 `INTERNAL_ONLY` / `PUBLIC_NO_CONSUMER`，同时保留宏生成、模板实例、静态链接和未覆盖架构等限制？当前尚未据限定扫描的阴性作这两种分类。

这不是请求每批开工许可，也不是请求扩大资源或改平台代码。它影响最终互斥分类口径；与之无关的阳性证据已继续补齐。

其他缺口逐项列在两批的 `W1/reviewed/` 中：包括外层对象的真实消费者、回调的间接调用链、异常传播路径、生成头/编译配置，以及同名库的实际绑定。不存在“再跑一次名字检索就能补全全部未定项”的证据。

原十二项的具体原因见 `W1/ORIGINAL_12_GAPS.md`。其中当前已观察的真实运行库关系单列，不因此把候选排除出可能的业务边。
