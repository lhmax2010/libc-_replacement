4. **扫描不等于定界**：公开安装头内的限定名命中可能是函数体、默认模板参数、派生类型的 trait、私有字段或嵌套成员；需逐项核对声明及真实消费方，不自动套三类标签。std::string 与 basic_string 是两个候选名字，不宣称两个独立底层类型。
5. **范围限制**：既有 R26 符号材料、P7 devel 头材料是冻结扫描范围，不包括所有外部产品/应用。未映射的别名、宏、using namespace 后的无限定名，以及未编译的模板实例，均不能从文本零命中推出不存在。形参或返回值的整数别名也可能在修饰名中只剩内置类型。
6. **执行偏差**：W0 首次 git commit 在 git add 结束前启动，报无已暂存修改；随后待 add 完成后重试普通 commit 成功，没有修改历史或 force。W1 初次正向对照把跨行 std 限定名的起始行误写成类型名所在行，断言拦住后修正为 std 所在第 3 行；未将失败扫描用于定界。
