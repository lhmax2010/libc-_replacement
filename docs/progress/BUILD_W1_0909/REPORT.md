## armv7l 固定基线对照的限定

固定快照为 `Tizen/Tizen-Base/tizen-base_20260827.214809`，候选则在
2026-09-09 的滚动 reference 环境构建。RPM 文件路径集合与 MLGO 接口
集合相同，但 requires diff 为 37 行、定义动态符号 diff 为 15,020 行。
因此这里只能证明候选的条件分支选择、资产来源与标准库身份正确，不能
把环境漂移下的整包差异宣称为本次修改前后完全一致。

要闭合该格，需要在同一固定仓集合、同一构建环境中，对未改 baseline
spec 与候选 spec 分别构建后比较，而不是拿跨日期已发布 RPM 代替同环境
对照。这是本报告采用的保守判据，不改变实现设计。
