# R19 + R20 + R21 证据包

- `R19/`：Chromium 当前 C++ 运行时、展开器、spec 与 ABI 标识。
- `R20/`：源码包级 C++ ABI 图、机械分阶段清单和交叉校验。
- `R21/`：T1/R1、首批五包、R14b 动态实验、T4 门禁、R13 闭包的具体复现清单。
- `inputs/input_identity.tsv`：本轮复用输入的路径、大小和 SHA256。
- `commands/`：本轮命令原文、标准输出/错误和退出码。

本轮零构建、零安装、未重扫平台仓；Chromium 只从既有二进制解包缓存定向读取 42 个 ELF，并从 SRPM 流中提取单个 spec 成员，未展开源码归档。
