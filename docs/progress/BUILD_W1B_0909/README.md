# LLVM 门禁矩阵补测与闭合

本目录记录 LLVM TensorFlow 2.18 / MLGO 候选在 2026-09-11 的剩余门禁
验证及 2026-09-11 续跑闭合。上一轮已闭合格的原始证据位于
`docs/progress/BUILD_W1_0909/`；本目录不复制或重跑这些格，只在
`MATRIX.tsv` 标明来源。

建议阅读顺序：

1. `REPORT.md`：结论、完整十二格矩阵、续跑结果与推送记录；
2. `MATRIX.tsv`：机器可读矩阵；
3. `raw/`：命令原文、退出码和技术性失败说明；
4. `evidence/`：产品核查与同环境对照摘要；
5. `build_logs/`：压缩后的完整构建日志及校验值；
6. `code/`：本轮实际使用的核查脚本快照。

十二格现已全部闭合，并已按门禁要求普通快进推送到
`sandbox/lhmax2025/libcxx-ehabi-backport`。

`raw/001_*` 至 `raw/016_*` 是上一检查点的原始记录，其中“未推送”描述
的是当时状态；`raw/017_*` 之后记录本次续跑并给出最终推送结果。
