    libcxx: preserve forced unwind in header catch sites
    
    The iostream, future, and string catch-all paths can intercept the
    foreign forced unwind used by pthread cancellation.  Preserve the
    observable libstdc++ behavior by recognizing the libc++abi marker type
    before catch-all handlers and rethrowing it after committing any stream
    state required by the corresponding operation.
    
    Deferred futures need one additional state transition: if execution is
    cancelled before completion, restore the deferred bit under the shared
    state lock and notify all waiters so one of them can retry the callable.
    The wait loop rechecks the deferred bit after every wake-up and after a
    retry.  This matches libstdc++ call_once retry behavior.
    
    Async states use the same locked, idempotent, non-throwing transition
    primitive to publish broken_promise when they are not already ready.
    If the state is already ready the operation is a no-op.  The original
    forced unwind is always rethrown.

    the forced unwind.  It introduces no exported symbol.  The change does
    not alter normal results or ordinary exception transport.

    deferred retry, async completion, stream-state, concurrency, and the

}

void __assoc_sub_state::copy() {
  unique_lock<mutex> __lk(__mut_);
  __sub_wait(__lk);
  if (__exception_ != nullptr)
    rethrow_exception(__exception_);
}

void __assoc_sub_state::wait() {
  unique_lock<mutex> __lk(__mut_);
  __sub_wait(__lk);
}

void __assoc_sub_state::__sub_wait(unique_lock<mutex>& __lk) {
  while (!__is_ready()) {
    if (__state_ & static_cast<unsigned>(deferred)) {
      __state_ &= ~static_cast<unsigned>(deferred);
      __lk.unlock();
      __execute();
      if (!__lk.owns_lock())
        __lk.lock();
    } else {
      __cv_.wait(__lk);
    }
  }
}
